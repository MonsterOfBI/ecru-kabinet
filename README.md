# ECRU Кабинет

Демо-версия кабинета для сотрудников и руководителей магазинов ECRU: личные показатели, рейтинги, отчёты, награды, лента «Сообщество» и студия карточек.

* Все люди, магазины и цифры в демо выдуманы.
* Загруженные отчёты, публикации и настройки хранятся только в браузере того, кто их внёс, и никуда не отправляются.
* Сайт закрыт от поисковых систем.

Это сборка в один файл (`index.html`). Исходники ведутся отдельно.
